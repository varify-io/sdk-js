# Security

Report a vulnerability to security@varify.io, not in a public issue.

Include the package and version, what an attacker can do with it, and how to reproduce it. We confirm receipt within 3 business days and keep you updated until a fix is released.

## Supported versions

Only the latest release of each package gets security fixes. Before 1.0, that is the latest 0.x minor.

## Scope

`@varify-io/core` and `@varify-io/nextjs`. Reports about varify.js, app.varify.io or the delivery files go to the same address.
